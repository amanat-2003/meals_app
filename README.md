# Meals App

A Flutter application that allows users to browse, filter, and favorite different types of food recipes. The app features various food categories and detailed recipes, including ingredients and preparation steps.

## Features

- **Categories**: View and select from various food categories like Asian, Chinese, Quick & Easy, Hamburger, Desserts, etc.
- **Recipe Details**: Click on a food item to see detailed steps and ingredients required to prepare the dish.
- **Favorites**: Mark your favorite dishes and view them on a separate page.
- **Filters**: Apply filters to view recipes based on dietary preferences such as vegan, vegetarian, lactose-free, and gluten-free.
- **State Management**: Utilizes Riverpod for state management.
- **Local Storage**: Uses Shared Preferences to save selected filters and favorite foods.

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/amanat-2003/meals_app
    ```

2. Navigate to the project directory:
    ```bash
    cd meals_app
    ```

3. Install dependencies:
    ```bash
    flutter pub get
    ```

4. Run the app:
    ```bash
    flutter run
    ```
